# ЧЗ_КонтрольПроведенияМаркировки — подпись события ПередПроведение

Назначение: блокировать проведение Перемещение/Реализация/ЗаказНаряд без КМ (требования 4, 6).

## Метаданные подписки (для Designer)
- Имя: ЧЗ_КонтрольПроведенияМаркировки
- Событие: Документ.ПередПроведением
- Виды документов (подписка на несколько событий):
  - Документ.ПеремещениеТоваров.ПередПроведением
  - Документ.РеализацияТоваровУслуг.ПередПроведением
  - Документ.ЗаказНаряд.ПередПроведением
  (имена видов Альфа-Авто сверить с метаданными — открытый вопрос п.11; при расхождении
   добавить кандидатов в список и в функцию ТребуетсяМаркировкаПоВиду модуля.)

## Модуль
Файл: ЧЗ_КонтрольПроведенияМаркировки.Модуль.bsl
Подпись обработчика в реальном коде: `Процедура ПередПроведение(ИмяОбъекта, Отказ, РежимПроведения)` —
параметр ИмяОбъекта даёт ссылку на документ; в модуле выше это учтено через ПолучитьОбъектПодписки()
(при интеграции заменить на `Документы[ИмяОбъекта].Найти(...)` / ДокМенеджер).

## Приёмка (тест 4)
- Добавить маркированную строку → окно сканирования открывается автоматически (расширение формы).
- Попытка проведения без КМ → Отказ = Истина + сообщение + запись «БлокировкаПроведения» в ЧЗ_ЖурналОбмена.
