# Описание структуры регистров сведений расширения «ЧестныйЗнак_Расширение» v1.0.0
# Формат: псевдо-конфигурация для последующей сборки в Designer/EDT.

## РегистрСведений.ЧЗ_МаркиИзЭДО (требование 1)
Измерения:
  - КодМаркировки: Строка(200), Ведущая
  - ДиадокDocumentId: Строка(200), Ведущая
Реквизиты:
  - ДокументПоступление: ДокументСсылка.ЛюбаяСсылка (в конфиге — ЛюбаяСсылка через реквизит без строгого типа, см. примечание)
  - ДатаИзвлечения: Дата
  - Статус: Строка(20)  # Извлечен | Загружен
  - ДатаЗагрузки: Дата
Режим записи: Независимый. Основной язык: Русский.

## РегистрСведений.ЧЗ_ОборотМарок (требования 3,5,6)
Измерения:
  - КодМаркировки: Строка(200), Ведущая
Реквизиты:
  - Статус: Строка(20)  # ВОбороте | Списан
  - ДокументСписания: ДокументСсылка.ЛюбаяСсылка
  - ПричинаСписания: Строка(40)  # ENTERPRISE_USE и др.
  - ИННПокупателя: Строка(13)
  - ДиадокDocumentId: Строка(200)
  - ДатаОперации: Дата
Режим записи: Независимый.

## РегистрСведений.ЧЗ_СвязиДокументовЭДО (требования 2,5; страховка РЗ п.4.4)
Измерения:
  - Документ1С: ДокументСсылка.ЛюбаяСсылка, Ведущая
  - ДиадокDocumentId: Строка(200), Ведущая
Реквизиты:
  - Направление: Строка(10)  # Inbound | Outbound
  - СтатусПоследний: Строка(60)
Режим записи: Независимый.

## РегистрСведений.ЧЗ_ЖурналОбмена (все требования; диагностика)
Измерения:
  - ДатаВремя: Дата, Ведущая
  - Событие: Строка(100), Ведущая
Реквизиты:
  - Документ1С: ДокументСсылка.ЛюбаяСсылка
  - ДиадокDocumentId: Строка(200)
  - КодМаркировки: Строка(200)
  - Результат: Строка(20)  # Успех | Предупреждение | Ошибка
  - Комментарий: Строка(1000)
  - Пользователь: Строка(100)
Режим записи: Независимый.

Примечание: тип «ДокументСсылка.ЛюбаяСсылка» недостижим напрямую; в реальных метаданных
используется тип «СправочникСсылка.Номенклатура»? — НЕТ. Используется типизация через
квалификаторы: для совместимости с Альфа-Авто задаётся как «ДокументСсылка.<вид>» либо
«ЛюбаяСсылка» (поле не индексируется как измерение). Решение принято по architect: измерения
хранят ссылку как Строку (Представление + GUID), а Реквизит Документ1С — тип ЛюбаяСсылка.
